Upload a CSV containing nursing examination questions and validate it before importing into the Exam Vault.

CSV format compatibility

PulsePrep accepts both the original 11-column question format and the newer 14-column format. If your file contains an id column, it will be ignored and the database can generate its own ID. Missing optional metadata such as source, school, academic year and status will be filled automatically.
